# 🚀 Assessment Técnico - Plataforma de Inmersión Cultural

## 📖 Descripción del Proyecto
Este repositorio contiene el desarrollo de una prueba técnica (assessment) enfocada en la programación y maquetación de una plataforma web interactiva de inmersión cultural (Masimo Stork). 

🔗 **[Visita el proyecto en vivo haciendo clic aquí](https://sebastianrodriguez02.github.io/assessment-developer/)**

## 📚 Historia y Contexto
Este proyecto fue construido como parte de un proceso de selección para un rol de desarrollo Front-End. El objetivo principal fue demostrar mi capacidad para tomar un diseño UI/UX entregado previamente (vía Figma) y replicarlo fielmente en código cien por ciento funcional.

Aunque el proyecto nació como una prueba técnica, lo mantengo en mi portafolio porque refleja mi habilidad para integrarme a flujos de trabajo corporativos, seguir lineamientos de diseño estrictos y construir experiencias de usuario interactivas a partir de requerimientos reales.

## 🔨 Estructura y Funcionalidades

La aplicación destaca por su interactividad y fidelidad al diseño original:
*   **Integración y Maquetación Fiel:** Replicación exacta del diseño propuesto, respetando tipografías, márgenes, jerarquías visuales y la paleta de colores corporativa.
*   **Sistema de Gamificación:** Implementación de la lógica para un sistema de progreso donde el usuario debe alcanzar 100 puntos y recolectar medallas navegando por el contenido.
*   **Navegación Dinámica:** Menú lateral funcional dividido en tres categorías principales (Culture specifics, Client specifics, Industry specifics).
*   **Componentes Interactivos:** Programación de vistas con elementos interactivos, como la selección de meses para verificar festividades (Holidays) o la exploración de estaciones del clima.
